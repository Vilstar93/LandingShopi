# LandingShopi

Портал заявки за изграждане на Shopify магазини за български фирми.

Фирмата попълва данните си. ЕИК се проверява веднага в браузъра, ДДС номерът
се проверява срещу VIES, и след приета заявка се показва бутон към Shopify.

## Какво прави

| Стъпка | Къде | Какво |
|---|---|---|
| ЕИК | браузър | Контролна цифра, офлайн, мигновено |
| ДДС | сървър | VIES, защото VIES не изпраща CORS заглавка |
| Заявка | сървър | Проверка на полетата, rate limit, препращане |
| Shopify | браузър | Бутон, само след заявка, само при клик |

## Защо ЕИК проверката е офлайн

`public/lib/eik.js` се ползва **и от браузъра, и от сървъра**. Така двете
страни не могат да се разминат в преценката какво е валиден ЕИК.

Алгоритъмът е потвърден срещу 10 ЕИК-а от registri.bg (препубликува
официалните отворени данни на Търговския регистър): 10/10 минават. Сбъркани
цифри, разменени цифри и нули се отхвърлят.

## Защо ДДС проверката е на сървъра

VIES **не изпраща `Access-Control-Allow-Origin`**. Браузърът не може да го
извика директно, затова `api/verify.js` го проксира.

Ключово: `MS_UNAVAILABLE` и `MS_MAX_CONCURRENT_REQ` се връщат като
`unavailable`, **никога** като `invalid`. Заета услуга не бива да отхвърля
реална фирма.

## Защо афилейт линкът не се пипа

Операторският линк е `https://shopify.pxf.io/7950557-link?sharedid=7950557`.
`sharedid` е идентификаторът на оператора в Impact.com.

Референтната имплементация (VZGplattform) строи URL с `searchParams.set`,
което **презаписва** съществуваща стойност. Ако `subIdParam` се конфигурира
като `sharedid`, операторският идентификатор се губи. Възпроизведено.

Тук `clickId` се **добавя** с `append` към отделен параметър (`subId1`).
`sharedid` остава непокътнат. Има регресионен тест.

## Афилейт разкриване

Страницата казва ясно, че операторът е Shopify афилейт и може да получи
комисионна, без това да променя цената за клиента. Линкът се активира само
след изпратена заявка и само при реален клик — без нов таб, без popup, без
iframe.

## Структура

```
public/           страница, стилове, клиентски код
  lib/eik.js      ЕИК валидация — споделена със сървъра
api/
  verify.js       VIES прокси
  _vies.js        VIES клиент (само сървър)
  submit.js       заявка -> афилейт линк
lib/affiliate.js  строене на афилейт линк
tests/            53 теста
scripts/
  dev-server.mjs  локален сървър
```

## Настройка

```bash
cp .env.example .env
# попълни SHOPIFY_AFFILIATE_URL
```

| Променлива | Задължителна | Какво |
|---|---|---|
| `SHOPIFY_AFFILIATE_URL` | не | Partner линкът. Празна → без Shopify бутон. |
| `REQUEST_WEBHOOK_URL` | не | Къде се препращат заявките. Празна → само лог. |

## Локално

```bash
npm test                      # 53 теста
node scripts/dev-server.mjs 3000
```

## Деплой

```bash
npx vercel --prod
```

`vercel.json` задава CSP, `X-Frame-Options: DENY` и `no-store` за API-то.
